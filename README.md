# Inked in Leonida

A night-shift tattoo parlor game on the Leonida strip: design every piece yourself, place it anywhere on the client, and live with the reaction.

Built with Unlayer React Image Editor. #BuiltWithImageEditor

> Work in progress (Phase 0 scaffold).

## Run locally

```bash
npm install
npm run dev
```

The editor loads from Unlayer's CDN, so it needs a network connection.
